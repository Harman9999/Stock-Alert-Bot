This AI-powered Discord bot, which is very
useful for the stock market. This bot lets you set stock/crypto alerts
and check prices, and my personal favorite feature is AI-powered
news. The news that the bot provides is made by taking multiple
articles from different sources via API and then sorting them through
a program I made with Python. The sorted articles are then sent to
the AI to determine the sentiment of the news, indicating whether
it is bullish or bearish, to assess the importance of the news on a
scale of 1 to 10, and finally to identify the stocks or cryptocurrencies
affected by it. I sort the news out in my program before I send it to
the AI because it costs money to go through all of the articles, and
it can be inefficient if the same article or a non-trustworthy source
is pulled; with the help of this program, it removes any extra costs,
keeping the news clean and efficient. 

Technologies used for this project include Python, Discord.py, OpenAI API, SQLite, Finnhub API, Coindesk RSS, and Alpaca API.
